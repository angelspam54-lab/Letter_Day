# Letter Day

The classic game of Name, Animal, Place, Thing, as a daily web game with a live party mode.

## Daily Letter
- Everyone gets the same letter each day, with a 60-second timer.
- Fill in Name · Animal · Place · Thing · Food, plus a rotating bonus category such as Colour, Job or Sport.
- Rarer answers score more, compared with everyone who played that day:

  | Tier | When | Points |
  |---|---|---|
  | ★ Only you | nobody else gave it | 30 |
  | Rare | under 10% of players | 20 |
  | Uncommon | under 30% | 15 |
  | Common | 30% or more | 10 |

  Finishing early adds a speed bonus of up to +15.
- Answers are checked against built-in word lists, with plurals and one-letter typos allowed. Unknown answers are *pending*: they count once 3 players give the same answer, or when a friend group votes them in.
- You get streaks, levels, stats (your rarest answers, how rare your answers usually are), daily ranks, and a spoiler-free share card that shows how rare your answers were, not what they were.

## Friend Groups
- Share a `/g/<code>` link and anyone who opens it joins.
- Everyone plays the daily letter. Answers stay hidden until you've played, then you compare them side by side.
- Members vote 👍/👎 on pending answers.
- Each group has a today ranking and an all-time ranking.

## Party Rooms (live)
- Share a `/p/<CODE>` link.
- The host picks the number of rounds (3, 5 or 8) and the time limit (60, 90 or 120 seconds). Round 1 can use today's letter.
- The letter is revealed with a spin. Players see each other's progress while they type.
- **The first player to fill every box calls STOP**, and everyone gets 2.5 seconds to finish.
- Review: answers are shown side by side, and players vote on unknown ones.
- Classic scoring: 10 for a unique answer, 5 for a shared one.
- A dropped player reconnects with their seat and score kept.

## Run locally
```
npm install
npm run build
npm start          # http://localhost:8787 (embedded database; no setup)
```
Run the tests with `npm test`.

## Deploy
Letter Day needs a running server: rarity scoring compares all players, and Party Rooms are live. That means static hosting such as GitHub Pages won't work. Use any Node host with PostgreSQL:
- **Render:** `render.yaml` is included. In Render choose New > Blueprint and pick the repo; it asks for `DATABASE_URL`: paste the connection string of a free Neon (neon.tech) database. `PUBLIC_URL` defaults to the Render address.
- **Docker:** a `Dockerfile` is included.
- **Fly.io / Railway:** both work.

Environment variables:
- `DATABASE_URL`
- `PUBLIC_URL`: the https address used in share links
- `TRUST_PROXY=1`: when behind a proxy
- `LAUNCH_DATE`: the date of day #1

Party Rooms are held in memory, so run a single instance. Moving rooms to Redis would allow more instances.

## Rarity before there are many players
`server/src/data/expected.json` lists the answers most people give for each category and letter, with a rough share of players. Rarity blends it in as if 20 people had already played, fading out once a category has 200 real answers, so obvious answers (Dog for D) don't score as rare on quiet days. Combo answers (a known word plus a word from the category: "Duck egg", "Van tyre") count, but score at most "uncommon". Hand-added words (Nigerian states, names, foods, planets and more) live in `server/src/data/words/extra/`; `extra/name-nicknames.txt` adds short forms like Vicky and Trish from [carltonnorthern/nicknames](https://github.com/carltonnorthern/nicknames) (Apache 2.0).

## The Ladder
A daily word ladder (`/api/ladder`, `server/src/lib/ladder.ts`, rules in `shared/ladder.ts`):
- the start and end words hide behind short clues (`server/src/data/ladder/clues.json`); solve them for points or reveal them;
- climb one word at a time; par is the shortest route through everyday words, and beating it scores extra (golf style);
- a twist each day, in turn: Classic, Extra moves (add, drop or shuffle letters), Locked letter;
- gold words: words on the day's theme (from Letter Day's category lists) score a bonus when they're on your route;
- a hint adds the next step of a shortest route.
Party Rooms can play a **Ladder race** instead of letter rounds: same ladder for everyone, points by finishing place.
Word data is built by `tools/build-ladder.mjs` from [SCOWL](http://wordlist.aspell.net/) word lists (via `wordlist-english`, MIT) plus Naija words.

## The Clue preview
`CLUES=server/src/data/clues.json npx vite build -c client/vite.preview.config.ts` (run in `client/`), then `node scripts/inline-preview.mjs client/dist-preview out.html` makes a single HTML file that plays every Clue set in the browser with no server.

## Word lists
`server/src/data/words/*.txt` is generated by `tools/build-words.mjs` (`cd tools && npm i && node build-words.mjs`) from:
- [WordNet 3.1](https://wordnet.princeton.edu/) (WordNet licence): animals, foods, things, places and the bonus categories, by walking each concept's "kind of" tree
- `human-names` (MIT): first names
- `all-the-cities` (GeoNames, CC-BY 4.0): cities with 20,000+ people
- `world-countries` (ODbL): countries and capitals
- hand-picked top-ups for common answers the datasets miss

Fonts: Bricolage Grotesque and Figtree (SIL OFL 1.1, see `server/assets/fonts/`).
